# Приложение с видеоплеером

## 📌 Описание проекта

Веб-приложение с интерактивным интерфейсом и адаптивным дизайном. Проект реализован по макету Figma с акцентом на качественную стилизацию и удобные элементы формы.

## 🛠 Стек технологий

- HTML5 - семантическая разметка
- CSS3 - современные стили
- Flexbox - гибкая организация элементов
- Grid Layout - сложные сетки
- Figma - работа с дизайн-макетом

## ✨ Реализованная функциональность

- Полностью адаптивный интерфейс
- Стилизация всех UI-компонентов
- Оптимизированные формы ввода
- Кроссбраузерная верстка
- Чистый и поддерживаемый код CSS
- Точно соответствие макету Figma

## 🚀 Как запустить проект

Клонируйте репозиторий

```
git clone https://github.com/ваш-username/posmotri-v-okno.git
cd posmotri-v-okno
```

Откройте файл index.html в браузере
